Bank Account Classes¶

Module: bank_account Description: Defines the BankAccount abstract base class which implements core banking functionality and the Subject role in the Observer pattern.

This module provides: - Basic account operations (deposit, withdraw, balance updates) - Service charge calculations - Transaction monitoring and notifications - Observer pattern integration for client notifications

Classes:

class bank_account.bank_account.BankAccount(account_number: int, client_number: int, balance: float, date_created: date)¶

Abstract base class representing a bank account with observer notification capabilities. Implements the Subject interface to notify observers of significant account events.

class bank_account.chequing_account.ChequingAccount(account_number: int, client_number: int, balance: float, date_created: date, overdraft_limit: float, overdraft_rate: float)¶

Represents a chequing account with overdraft capabilities. Extends BankAccount to add overdraft limit and rate functionality.

Attributes:

_ChequingAccount__overdraft_limit (float): Maximum allowed overdraft amount, typically negative _ChequingAccount__overdraft_rate (float): Interest rate applied to overdrawn amounts _ChequingAccount__strategy (OverdraftStrategy): Strategy for calculating overdraft charges

Business Rules:

  • Default overdraft limit is -100.0 if invalid input provided

  • Default overdraft rate is 0.05 (5%) if invalid input provided

  • Service charges increase when balance falls below overdraft limit

Raises:

ValueError: If account_number is not an integer (from parent class) ValueError: If client_number is not an integer (from parent class)

get_service_charges() → float¶

Calculate service charges using the overdraft strategy.

Returns:

float: Total service charges calculated by the strategy

Note:

Delegates to OverdraftStrategy for charge calculation based on balance and overdraft limit. Falls back to manual calculation if strategy fails.

class bank_account.investment_account.InvestmentAccount(account_number: int, client_number: int, balance: float, date_created: date, management_fee: float)¶

class client.client.Client(client_number: int, first_name: str, last_name: str, email_address: str)¶

Represents a client with client number, first name, last name, and email. Implements the Observer interface to receive notifications.

Attributes:

_Client__client_number (int): Unique identifier for the client _Client__first_name (str): Client’s first name, non-empty string _Client__last_name (str): Client’s last name, non-empty string _Client__email_address (str): Valid email address or default if invalid

Business Rules:

  • Client number must be an integer

  • First and last names cannot be blank or whitespace

  • Invalid email addresses default to “email@pixell-river.com”

  • Notifications are sent via email with timestamp

Raises:

ValueError: If client_number is not an integer ValueError: If first_name is blank after stripping ValueError: If last_name is blank after stripping
